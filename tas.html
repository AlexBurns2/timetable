TAS

Tool-assisted speedruns. Bots, scripts and frame-by-frame play are all allowed here, so this is where the machine limit gets set. Every run is a movie, one input per frame, played back on the server from a fixed seed. If it finishes, it counts. Fewest frames wins, and the first to get there keeps a tie. The normal leaderboards stay for people playing live.
