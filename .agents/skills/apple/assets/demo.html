Product UI

Familiar where it matters.

Two layers. Content scrolls; controls float on glass and stay quiet. Scroll the screen to see the edge effect appear under the toolbar.

  • Glass only on controls — toolbar groups and the tab bar, never on list rows.
  • One tinted action. Done is the only colored control.
  • Concentric corners everywhere, capsules for touch.
  • Inset grouped lists with separators aligned to the text.
